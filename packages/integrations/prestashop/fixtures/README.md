# PrestaShop fixtures

Fictional shop data for the read-only client and mapper.

modelled on PrestaShop 1.7.7 JSON output; checked against the live shop at R1-H.

Some resource ids are JSON numbers, which is how PrestaShop 1.7.7.2 hydrates them. Money fields stay decimal strings.

Emails use the `.test` domain. Names, addresses and identifiers are invented. A few extra `display=full` fields are present so the client can show that it drops them.
