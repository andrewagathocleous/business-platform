# OWASP ASVS 5.0, Level 2-oriented checklist

Version 0.2, 2026-10-22. This is a **chapter-level** tracker. Item-level mapping (each `V#.#.#` with evidence) is still open: it is a Phase 1 exit task for the chapters marked _P1_ and a pre-production gate for all chapters. Status values are `not started`, `in progress`, `evidence: <test/file>`, `n/a (reason)` and `gap (reason)`.

Test levels below mean: unit tests, or integration tests against real Postgres. Nothing in this checklist is sandbox-tested or live-tested. Shopify and printing evidence is for the mocks.

## Known gaps at the end of Phase 1

- Playwright is not in CI. `.github/workflows/ci.yml` has no e2e step. `pnpm test:e2e` is local only.
- The images were not built (`docs/STATUS.md`: free disk was below the 15 GB gate) and they are not scanned.
- CI does not fail on dependency findings. `pnpm audit --prod --audit-level high` is `continue-on-error: true`. There is no image scanning step.
- Backups are not implemented. [docs/runbooks/backup-restore.md](../runbooks/backup-restore.md) is a design.
- The SPA CSP in `infra/caddy/app.caddy` has not been verified in a browser against the built stack. `pnpm milestone:csp` has not been run.
- There is no break-glass account and no recovery runbook.
- The SSRF-safe HTTP client, email HTML, CSV formula protection and alerting are later phases, as marked in the table.
- Item-level `V#.#.#` evidence is not filled in.

## Pre-production review plan (Phase 5)

1. Complete the item-level evidence for all chapters, with gaps explicitly accepted or fixed.
2. Re-run the threat model with the integrations as actually built.
3. Dependency, image and secret scans with no unresolved high or critical findings.
4. External exposure test from the internet: only 80/443 open; the n8n editor and DB unreachable.
5. Restore drill on a clean VPS, with the results recorded.
6. Optional independent penetration test before onboarding any company the owner doesn't operate.
